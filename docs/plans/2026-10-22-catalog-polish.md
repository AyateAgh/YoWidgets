The current user request is the implementation brief. Preserve the black shell, original ring and native engine. Improve real discovery/management rather than changing the product identity.

2. Completed Downloads navigate to Library. One Clear finished command clears terminal history only, preserving installed resources and active jobs.
3. Shared optimistic settings switches, stable geometry/focus and per-field pending state; no global disabled flash. Avoid refreshing/repositioning native windows for unrelated interface settings. Test delayed/failed responses and stale snapshots.
4. Local ZIP import: catalog.json + declared packages under packages/. Validate hashes, types, paths, size/dependency bounds with the existing ContentStore; no downloaded executable modules or arbitrary URL fetches. Preview metadata and install explicitly, with local ownership and removal. The native file picker is intentional.
5. Preview motion runs only while hovered/focused and visible; respect reduced motion. Clock seconds, small player waveform and weather sheen remain illustrative previews.
6. Appearance owns neutral plus seven subtle accent choices and Auto from a local wallpaper thumbnail, with Windows accent fallback. Only color is returned to UI; no wallpaper path/image leaves native code. Existing live widget backdrops remain compositor based.

Canonical owners: catalog.ts for content/version state; shared Switch/ToggleRow + optimistic settings hook for toggles; existing Radix Modal/Dropdown; native DesktopPlatform commands and ContentStore for persistent resources.
