# Privacy

YoWidgets stores settings, installed content and encrypted connection keys locally. Windows DPAPI binds saved keys to your Windows account. Management receives connection status and model preferences, never stored keys. No analytics or advertising service is included.

Home checks the public GitHub catalog and downloads selected packages. GitHub receives ordinary network request information. Library reads local state and works offline. Packages are size and SHA-256 checked before registration; checksums are not publisher signatures.

Optional features make requests: weather uses your configured city; lyrics send track metadata to LRCLIB when enabled; assistant messages and selected attachments go to your chosen provider when you send or check a connection. Live voice streams audio during a connected call. Opening management does not upload original files or photos. Browser companions and agent access are optional, with permissions described in the README.

Interface sounds are generated locally and off by default. Management uses a separate WebView2 profile. Clearing its cache does not erase app credentials. Uninstall removes app-owned settings, keys and content; independently installed browser extensions must be removed in the browser.

Logs and settings may contain private paths or provider errors. Review them before sharing. Never put keys in issues, screenshots or the repository.
