# YoWidgets

Нативные виджеты для Windows 11: шейдерное стекло с преломлением обоев, часы, календарь, погода, музыка, фото, Focus/Pomodoro, быстрые настройки, необязательные уведомления и ИИ. Текущая версия — 0.1, первая рабочая сборка с явно обозначенными ограничениями.

## Установка

Запустите `scripts/install.ps1` из PowerShell после сборки. Программа устанавливается только для текущего пользователя в `%LOCALAPPDATA%\Programs\YoWidgets`, запускается без прав администратора и не включает автозапуск самостоятельно. Папка данных — `%LOCALAPPDATA%\YoWidgets`.

Окно управления закрывается в трей. Для включения виджета используйте переключатель; «+ Ещё один» создаёт экземпляр. Свободная область виджета перетаскивается мышью; стрелки и Shift+стрелки дают перемещение без перетаскивания. Правый клик — размер и выключение. В настройках доступны город, тексты песен, источник музыки, автозапуск и подключения.

Snooze закрывает поверхности, отменяет сетевую работу, останавливает периодические обновления. Повторное нажатие возвращает включённые виджеты. «Отключить всё» также выключает автозапуск и сохранённые opt-in уведомлений/текстов. Сами настройки сохраняются.

## Удаление

У установленной копии: «Отключение и удаление» → конечная кнопка «Удалить полностью». Страница заранее перечисляет удаляемые данные. Результат показывает отдельное окно очистителя. При чужом/заблокированном файле удаление честно считается частичным, а скрипт повторной очистки сохраняется.

Также доступна запись YoWidgets в установленных приложениях Windows и `uninstall.ps1` внутри папки установки. Очистка не удаляет исходные фото, папку проекта/examples, Windhawk, общие .NET runtime и чужие файлы. Возврат громкости/яркости — отдельный выбор с проверкой внешних изменений. Удаление не отменяет уже выполненные запросы к внешнему провайдеру.

В сборке из исходников/неустановленной папки удаление проекта заблокировано. Используйте per-user установку для полного управляемого удаления.

## Подключения и ограничения

- **Стекло:** HLSL/PS 3.0, аппаратный рендеринг WPF. Преломляется соответствующая область системных обоев, как у настольных виджетов MacShell. Произвольные окна и сторонние видеообои не захватываются. Слабый GPU/RDP/отключённые эффекты требуют отдельного испытания; это не нативный материал Apple.
- **Погода:** Open-Meteo, ограниченный резервный запрос к wttr.in при сетевом сбое, локальный кеш. Передаётся выбранный город; IP-геолокация не используется. Ошибка и отсутствие данных не заменяются демонстрационными числами. Источник/время доступны в подсказке виджета.
- **Музыка:** системные медиасессии Windows. Источник должен предоставлять данные и команды. Недоступные перемотка/повтор/перемешивание отключены. Тексты LRCLIB запрашиваются только после включения.
- **Уведомления:** нужны package identity и разрешение Windows. В этой поставке регистрация не выполняется скрыто. `packaging/AppxManifest.xml` и парные dev-скрипты подготовлены; для local development необходимы уже разрешённые Windows prerequisites. Для обычной поставки нужен подписанный identity-only пакет. Лента не перехватывает все чужие всплывающие окна и не подавляет системные уведомления.
- **ИИ:** укажите собственные HTTPS endpoint, модель и API-ключ. Запросы выполняются только по кнопке, ключ защищён DPAPI текущего пользователя. Экран, фотографии и уведомления автоматически не передаются. Без провайдера виджет показывает настройку подключения.
- **Focus:** локальный таймер и Snooze. Системный DND открывается в штатных настройках; приватные обходы Windows не используются. Wi-Fi открывает штатные настройки.
- **Рабочий стол:** проверяемая привязка собственных окон к доступному слою Explorer. Несовместимый DPI/потерянный родитель скрывает поверхность с объяснением и кнопкой переподключения. Можно отключить настольный режим и использовать обычные окна/режим поверх окон. Официальный IVirtualDesktopManager не содержит PinWindow; поведение на всех виртуальных столах не заявляется гарантированным.

## Сборка и проверки

Нужен .NET SDK 10.0.402. Локальный SDK этой рабочей копии лежит в `.tools/dotnet` и не устанавливался глобально. `scripts/build.ps1` запускает тесты, компилирует HLSL через системный D3DCompile и создаёт самодостаточную Windows x64 сборку в `artifacts/release`.

```powershell
.\.tools\dotnet\dotnet.exe run --project tests/YoWidgets.Tests -c Release
.\scripts\build.ps1
.\tests\lifecycle.ps1
```

`YoWidgets.slnx` открывает исходники в IDE. Для самостоятельного клонирования установите совместимый SDK из официального дистрибутива Microsoft и настройте локальный путь; автоматическое включение Developer Mode, импорт сертификатов и изменение системных runtime не выполняются.

Фактические результаты и непроверенные сценарии: [docs/verification.md](docs/verification.md). Контракт очистки: [docs/cleanup-contract.md](docs/cleanup-contract.md).
