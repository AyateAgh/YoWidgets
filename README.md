# YoWidgets 0.6.2

## New catalog and library

**Home → Install** downloads a widget or collection. **Library → desktop switch** hides/restores its saved instances and positions; details offer additional instances and configuration. Update appears only for a newer catalog version. New profiles have no installed packs; existing widgets migrate locally with their settings. Search, type/collection/status filters, details and real download progress are included. Library and Settings work offline.

Library supports [local custom package ZIPs](docs/custom-packages.md), with metadata review before installation. Downloads separate cancellation from navigation to installed content, and Clear finished removes history only. Settings switches update immediately while writes remain serialized across navigation. Appearance offers Dark, Light and a custom one- or two-color theme, circular transitions, optional theme sounds, a transparent center, eight accents and opt-in local wallpaper matching. The weather target button can fill an editable city using ipapi.co; Save & refresh remains explicit. Hover previews animate only while visible and respect reduced motion.

The management interface uses an original empty-ring Yo mark, black 72 DIP rail and liquid selection. It runs separately from the native widget engine, sleeps when hidden and normally exits after 15 minutes. Unsaved settings drafts remain in memory until saved or discarded. Interface sounds are optional and off by default. Pets, taskbars, docks and system effects have reserved categories; their engines are not shipped yet.

Build on Windows 11 x64 with .NET 10 SDK and Node.js 24 LTS:

```powershell
./scripts/build.ps1
# artifacts/single-exe/YoWidgets.exe and artifacts/install-payload/
./scripts/install.ps1
```

The build generates the catalog, compiles and embeds the local React interface, runs native/frontend checks and publishes a self-contained executable. WebView2 Evergreen is checked when management opens; recovery offers Microsoft's installer if needed. The local `.tools/dotnet` SDK is used when available, otherwise the installed SDK.

Official feed: [catalog/v1/catalog.json](catalog/v1/catalog.json). Generate content with `node scripts/publish-catalog.mjs`. See [catalog authoring](catalog/README.md), [privacy](PRIVACY.md), [security](SECURITY.md) and the [platform specification](docs/plans/2026-10-21-premium-platform.md).

The older native widget documentation below describes the widget layer. Its former **Widgets → Explore** management navigation is replaced by Home and Library.

Нативные виджеты Windows 11 с английским интерфейсом. Два встроенных пака: **Glass** и **Liquid Glass**. В каждом — часы, погода, календарь, музыка, фото, Focus, быстрые настройки, уведомления и ассистент.

## Паки

Откройте **Widgets → Explore Glass / Explore Liquid Glass**. Переключатели, добавление ещё одного экземпляра и **Disable this pack** работают только внутри выбранного пака. Оба пака можно использовать одновременно. **All packs** возвращает в библиотеку.

- **Glass:** спокойная прозрачная поверхность, тонкий контур, небольшая доля живого размытия.
- **Liquid Glass:** оформление по референсам Apple, нейтральный оттенок, более объёмный световой край, плавная реакция на перетаскивание и раскрытие.

Старого переключателя материала в Appearance нет. Стиль хранится в каждом экземпляре виджета. Старые экземпляры автоматически переходят в Liquid Glass с сохранением ID, координат, размеров и включённых интеграций.

Оба пака используют текущий фон Windows Composition. Для подложки виджета файл системных обоев не читается; старые обои и кеши фона не подставляются даже при отказе эффекта. Поверх живого фона рисуется только прозрачный оптический край. Размытие выполняет GPU-композиция: Gaussian sigma 2 для Glass, 3 для Liquid Glass и 4.5 во время его движения. Параметры заданы паком, без отдельной настройки. При недоступности композиции остаётся нейтральная прозрачность.

Это Windows-адаптация по [документации Apple](https://developer.apple.com/videos/play/wwdc2025/219/), без официальной связи с Apple. Полное преломление произвольных окон, слияние форм и пиксельное совпадение с iOS 26 не реализованы. Превью в каталоге — небольшие авторские образцы стиля, не снимки рабочего стола.

## Работа и производительность

Перемещение выполняет штатный DragMove. Во время движения нет чтения обоев, декодирования изображений или записи экрана. Оптический шейдер не содержит сэмплера изображений. Подложки GPU-композитора принадлежат программе и закрываются вместе с виджетами.

Для контраста один общий фоновый обработчик раз в две секунды считывает четыре значения цвета у прозрачных краёв каждого видимого виджета. Изображения не создаются, не сохраняются и не передаются. Цвет текста плавно меняется между светлым и тёмным; гистерезис уменьшает мерцание. Это оценка окружения по краям, а не анализ всех пикселей под текстом. В Snooze и без активных виджетов обработчик остановлен.

**Snooze** закрывает поверхности и приостанавливает обновления; повторное нажатие восстанавливает включённые виджеты. **Disable all** также выключает интеграции и принадлежащий программе автозапуск. Часы без секунд обновляются на границе минуты; музыкальная шкала во время воспроизведения — 10 раз в секунду.

## Подключения

- **Погода:** выбранный город передаётся Open-Meteo; ограниченный резерв wttr.in при сетевом сбое. Локальный кеш без вымышленных значений. Прицел в настройках по отдельному нажатию запрашивает примерный город через ipapi.co; найденный город нужно проверить и сохранить.
- **Музыка:** системные медиасессии Windows, в том числе от установленных плееров; браузер не требуется. Команды исполняет источник. Shuffle/Repeat появляются только при поддержке музыкой, скрываются для видео/закрытой сессии. Плеер может предоставлять previous/next без shuffle/repeat. Если приложение не публикует медиасессию Windows, для него нужен отдельный адаптер; универсальная поддержка всех версий iTunes и сторонних клиентов не заявляется. Обложка трека → логотип известного сайта/приложения → полностью скрытая область обложки. Логотипы запрашиваются с публичных адресов по метаданным; вкладки/история браузера не читаются.
- **Lyrics:** включаются в Settings, название и исполнитель передаются LRCLIB. Кнопка появляется только после успешного поиска текста. Точные метаданные дополняются поиском с очисткой веб-заголовков и отделением исполнителя от загрузившего запись пользователя. Синхронизация построчная, от часов активной медиасессии; пауза и перемотка учитываются. Если длительность версии отличается, доступны только обычные строки с пометкой об отсутствии времени. Для неизвестных треков, инструментальной музыки, видео и сетевых ошибок кнопка скрыта. Аудио, содержимое вкладок и субтитры сайтов не записываются и не извлекаются. LRC не превращается в выдуманную синхронизацию каждого слова. Кеш ограничен 12 записями, запросы последовательны, Retry-After соблюдается.
- **Уведомления:** требуются package identity и согласие Windows. Автоматической регистрации нет; dev-скрипты парного подключения/удаления лежат в scripts. Лента не подавляет и не удаляет оригиналы уведомлений.
- **Ассистент:** Gemini, OpenAI, Claude, DeepSeek или OpenRouter, API-ключ защищён DPAPI, адрес сервера вводить не нужно. Потоковые ответы, контекст диалога в памяти, Markdown, копирование кода, остановка и повтор запроса. Enter отправляет, Shift+Enter добавляет строку; микрофон распознаёт запись через API Gemini/OpenAI или установленный движок Windows. Текст и контекст передаются только по Send. Содержимое экрана, уведомления и фото не включаются автоматически.
- **Управление:** громкость через CoreAudio, яркость поддерживаемых дисплеев через WMI. Wi-Fi и DND открывают штатные настройки Windows. Focus — локальный таймер.

## Файловый ИИ-агент

В виджете нажмите **+ → Files and folders**, выберите рабочую папку и отправьте задачу. Подключённая модель с поддержкой tool calling сможет читать и искать файлы, создавать папки и файлы, редактировать текст и удалять отдельные файлы внутри этой папки. Содержимое запрошенных файлов передаётся выбранному API-сервису. Без выбора папки локальные инструменты ограничены собственной папкой результатов приложения, когда включены режимы или плагины. Терминал не предоставляется; Computer use включается отдельно и запрашивает разрешение на управление конкретным окном в рамках задания.

В чате видны реальные действия, ошибки и карточка изменённых файлов с количеством добавленных/удалённых строк. Наведение на имя на 0,5 секунды открывает diff или превью изображения; нажатие открывает подробный просмотр. **Undo changes** восстанавливает исходные версии и сохраняет более новые ручные правки. История отмены хранится только в текущем чате до его очистки, смены папки или закрытия приложения. Ограничения одного задания: 1 МБ на текстовый файл, 8 МБ на документ, 40 изменённых файлов, 16 МБ снимков, 32 шага модели и 96 действий; ограничения времени ответа нет. Поддержка tool calling зависит от выбранной модели; настоящий запрос проверен с Gemini, остальные сервисы — транспортными тестами.

## Запуск, обновление и удаление

### Дополнительный мост SoundCloud

`integrations/browser-bridge` (также `artifacts/browser-bridge.zip`) — небольшое необязательное расширение Chrome/Edge. После ручной установки и обновления SoundCloud оно связывает Shuffle/Repeat виджета с настоящими кнопками сайта. Состояние читается обратно из источника; своя очередь не создаётся. Доступ ограничен SoundCloud и loopback-подключением к YoWidgets. Подробности, разрешения и удаление: [инструкция](integrations/browser-bridge/README.md).

Этот отдельно установленный компонент удаляется на странице расширений браузера; удаление Windows-приложения не убирает его запись из Chrome/Edge. После выхода/Snooze приложения соединение закрыто. Мост SoundCloud читает только метаданные и кнопки мини-плеера. Отдельный Assistant browser companion описан ниже. Для Spotify Web API нужен отдельный вход и разрешение аккаунта, ID трека недостаточно. Legacy iTunes COM в этой версии не добавлен.

Готовый переносимый файл: `artifacts/single-exe/YoWidgets.exe`. Установленная копия: `%LOCALAPPDATA%/Programs/YoWidgets/YoWidgets.exe`. Права администратора не требуются.

```powershell
./scripts/install.ps1
./scripts/update.ps1
```

Обновление сохраняет ваши данные. Полное управляемое удаление доступно в установленной копии: **Disable & uninstall → Uninstall completely**. Удаляются только принадлежащие установке файлы/регистрации/данные. Оригиналы фото, examples, исходники проекта, Windhawk и другие программы сохраняются. Откат громкости/яркости выбирается отдельно и проверяет конфликты. Сборка из исходников не может удалить исходный проект. Подробности: [контракт удаления](docs/cleanup-contract.md).

Рабочий стол и Explorer не модифицируются. Виджеты — независимые окна без рамки и значка на панели задач. Win+D и виртуальные рабочие столы следуют обычным правилам Windows; закрепление на всех столах не заявляется.

## Сборка и проверки

Локальный .NET SDK 10.0.402 находится в `.tools/dotnet`; глобально не устанавливался. Сборка компилирует HLSL PS 3.0 и публикует один self-contained x64 EXE.

```powershell
./scripts/build.ps1
./tests/localization.ps1
./tests/lifecycle.ps1
./.tools/dotnet/dotnet.exe run --project tests/YoWidgets.Tests -c Release
```

`tools/MediaFixture` — явно обозначенный тихий тестовый источник SMTC, без аудио и стороннего аккаунта. `tools/WallpaperProbe` — исторический диагностический инструмент; его диагностическое чтение обоев не используется для подложек виджетов. Отдельная настройка Auto accent читает миниатюру обоев только локально. Сторонний исполняемый код и публикация мастерской пока не поддерживаются.

Проверенные сценарии и ограничения: [verification](docs/verification.md). Сторонние компоненты: [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).


Чат: ожидание ответа API больше не ограничено таймером приложения; остановить запрос можно кнопкой Stop или Escape. Вложения отображаются плитками и внутри бабла отправленного сообщения. GIF передаётся модели как последовательность кадров; Gemini получает исходное видео, остальные модели со зрением — набор визуальных кадров без звука. Текстовые модели не могут анализировать изображения: несовместимость показывается явно. Поле ввода плавно растёт до четырёх строк, затем прокручивается.


## Меню чата, документы и приложения

Вставка **Ctrl+V** прикрепляет файлы из Проводника или изображение из буфера; обычный текст вставляется в строку ввода. На вложениях в черновике, чате и просмотре изменений доступны **Open / Copy / Download**. Нажатие на изображение открывает оригинал в приложении по умолчанию; исходный код открывается в собственном безопасном просмотре. Copy сохраняет точные байты исходного файла; Open не запускает исполняемые вложения. Ограничения: до 5 файлов, 8 МБ каждый, 12 МБ вместе с подготовленными кадрами. Неподдерживаемые форматы показывают понятную ошибку.

**+ → Files and folders** позволяет одним диалогом выбрать несколько файлов и одну рабочую папку. Изменение папки начинает новый чат, сохраняя ещё не отправленный черновик. **Goal** закрепляет первый отправленный промпт как цель текущего чата; последующие сообщения могут её уточнять. **Planning mode** требует решения о сложности до изменения файлов: небольшая задача обходится без плана, сложная сначала получает настоящий `PLAN-….md`. Для задачи с внешним образцом модель должна сначала прочитать источник. Режимы отключаются крестиком на плашке. История, цель, выбранная папка и режимы не являются фоновой службой и не продолжают работу после выхода из приложения.

**Draw** открывает центральный холст: перо, выделение, текст, прямоугольник/эллипс, ластик, размер, цвета, undo/redo. Галочка прикрепляет созданный PNG; закрытие отменяет рисунок.

В секции **Plugins** включаются настоящие встроенные инструменты, которые получают API-модели с поддержкой tool calling:

- **Media generation** — изображения и правки через Gemini, OpenAI, OpenRouter и Pollinations; видео через Gemini/Pollinations; аудио и 3D через Pollinations. Любая подключённая чат-модель с вызовом инструментов использует независимо настроенный генератор. Анимация создаётся только по явному запросу и экспортируется в GIF из короткого видео (до 10 секунд, 480 px, 10 кадров/с).

Медиа появляется в чате: точечный skeleton показывает реальный этап, числовой прогресс — только измеренную загрузку файла, когда известен его размер. Проценты генерации по таймеру не выдумываются. Левый клик открывает полноэкранный просмотр: Fit/zoom, воспроизведение и перемотка видео, галерея версий, Copy/Download, Markup для статичных изображений и поле для правок. Рисунок сохраняется отдельным PNG. **Edit in chat** выбирает версию как референс и переносит инструкцию в поле ввода; следующий Send выполняет правку. Крестик у референса отменяет его. Изменение чат-модели в том же сервисе с тем же ключом сохраняет разговор; смена сервиса или ключа очищает его. Открытый просмотрщик позволяет явно выбрать старое медиа после смены подключения.

Оригиналы сохраняются в `%LOCALAPPDATA%/YoWidgets/Assistant/Media`; чат остаётся в памяти. Файлы можно открыть/прикрепить повторно. Максимальный результат — 128 MB; входной референс редактора — 24 MB. Размеры, длина видео и доступность правок зависят от API и модели; OpenAI использует поддерживаемые квадратный/портретный/альбомный размеры. HTTP 429/отказ отображается как ошибка, предыдущие версии сохраняются. Наличие модели в списке ключа не означает наличие квоты генерации.

- **Documents / PDF** — чтение и анализ DOCX/PDF; создание DOCX/PDF с размерами страницы, полями, шрифтами, абзацами, интервалами, таблицами, изображениями, колонтитулами. PDF можно отрендерить для проверки. Сканированный PDF требует отдельного OCR, которого здесь нет.
- **Spreadsheets** — чтение и создание XLSX с листами, стилями, размерами строк/столбцов, объединением ячеек и поддерживаемыми формулами. Макросы и сетевые формулы не выполняются.
- **Presentations** — чтение и создание редактируемых PPTX: текст, формы, изображения, точные координаты, шрифты и размеры слайдов. Это инструменты со схемой поддерживаемых параметров; произвольные функции Office не эмулируются.
- **Browser use** — открытие публичных URL в видимых вкладках YoWidgets, чтение страницы и элементов, клики, ввод, прокрутка, навигация и реальные снимки страниц. Вкладки сохраняются после ответа; их можно закрывать отдельно. Нужен Microsoft Edge WebView2 Runtime. Существующие Chrome/Edge вкладки обнаруживаются через Windows; расширение даёт более полный доступ к DOM. Сессии Chrome автоматически не импортируются.
- **Computer use** — список окон, чтение UI Automation и снимок выбранного окна, плавный курсор, клики, Unicode-ввод, ограниченные клавиши, прокрутка и перетаскивание. Разрешение выдаётся конкретному окну на одно задание. Во время сеанса видны название модели, текущий этап, свечение по краям экрана и **Esc to cancel**. Esc или кнопка останавливает запрос и дальнейший ввод. Парольные поля, терминалы и защищённые приложения исключены; некоторые окна могут не отдавать снимок.

Вложения Office автоматически включают соответствующий документный модуль перед отправкой. Созданные файлы появляются в общей карточке изменений и поддерживают Open/Copy/Download и Undo. Если папка не выбрана, результат находится в `%LOCALAPPDATA%/YoWidgets/Assistant/Sessions/…`; его можно скачать через контекстное меню.

Откройте **+ → Browser tabs**: первые три обнаруженные вкладки показываются автоматически, остальные раскрываются кнопкой. Выбор существующей вкладки переключает её и прикрепляет проверенный URL; содержимое запрашивается моделью после отправки промпта. Windows-доступ может быть неполным. Для более полного чтения/управления используйте **Browser companion** и ручное сопряжение: [инструкция](integrations/assistant-browser-bridge/README.md). После перехода внешней вкладки на другой URL прикрепите её повторно. Для новых ссылок модель использует `browser_open` без расширения. Перед управлением приложение спрашивает разрешение для окна или сайта на текущее задание. Защищённые страницы, cross-origin iframe, canvas и действия с системными привилегиями могут быть недоступны. Само наличие API-ключа не гарантирует поддержку инструментов и изображений выбранной моделью.

Внешние аккаунты Codex/Claude/Antigravity, фоновая работа при закрытом YoWidgets и установка плагинов Codex в это приложение не входят. Все перечисленные инструменты реализованы внутри YoWidgets и используют выбранный API.

Меню «+» теперь использует настоящий glass backdrop с блюром и вращением плюсика; повторное нажатие закрывает меню. Плагины выбираются как синие метки-инструкции с иконкой в поле ввода, а не только галочкой: их инструкция передаётся в API вместе с запросом и сохраняется при Retry. Крестик убирает инструкцию из черновика. Введите `@doc`, `@pdf`, `@browser` и т. п., чтобы открыть и отфильтровать то же меню; ↑/↓ выбирают пункт, Enter/Tab подтверждает, Escape закрывает поиск. Email-адреса не считаются вызовами. Название и иконка выбранного модуля остаются в отправленном сообщении. При выключенных системных анимациях переходы применяются сразу; при недоступном композиторе меню остаётся контрастным и непрозрачным.


Computer use теперь включает `computer_list_apps` и `computer_open_app`: модель ищет установленное приложение и открывает его по найденному ID, затем читает реальное окно. Стандартные установки Telegram и Discord поддерживаются, включая запуск Discord через Update.exe. Свёрнутые окна видны и восстанавливаются перед управлением. Для URL в промпте доступны и браузерные инструменты, даже если выбрана только метка Computer use. В журнале — названия приложений/страниц, количество найденных окон и элементов, раскрываемые причины ошибок. Задания без изменения файлов показывают Activity без пустого блока 0 changed files. Во время управления по периметру монитора идут мягкие волны; указатель агента повторяет реальное положение мыши во время ввода и затем исчезает. Esc/Stop сохраняют своё действие. Полнота чтения чатов зависит от модели, входа в аккаунт и доступности интерфейса; успешный запуск сам по себе не считается чтением переписки.


## Отдельные API-ключи генерации

В **Settings → Generation connections** есть четыре независимых подключения: **Images**, **Video**, **3D models**, **Audio**. Для каждого выберите **Use chat connection**, **Separate API key** или **Off**, сервис и модель. **Connect Pollinations** позволяет вставить один ключ и нажать **Use for all media**; затем любую категорию можно переопределить. Ключ чата не заменяется. Ключи хранятся зашифрованными для текущей учётной записи Windows; пустое поле сохраняет прежний ключ.

**Check Pollinations key / Check key** проверяет подлинность ключа, его разрешения, срок действия, доступный баланс/бюджет Pollen и загружает каталог моделей, не запуская генерацию. Отсутствие разрешения на чтение баланса показывается отдельно от неверного ключа. Открытый каталог моделей сам по себе не доказывает работоспособность ключа. **Test generation · uses credits** делает один настоящий синтетический запрос выбранной модели; результат можно открыть и скачать. Автоматического перехода на другую платную модель нет.

Каталог показывает базовые цены Pollen, поддерживаемые входы/выходы, требование платного Pollen и опубликованные ограничения моделей. Тарифы и баланс меняются на стороне Pollinations; Quest-совместимость не означает безлимитную бесплатную генерацию. Выбранная по умолчанию Z-Image Turbo принимает только текст: для правок выберите модель с входом image. Некоторые 3D-модели требуют изображение. Аудио использует выбранную speech/music-модель; голос настраивается отдельно. Аудио воспроизводится в просмотрщике, GLB/PLY открываются в установленном приложении для 3D или скачиваются. Правки аудио/3D референсами пока не реализованы и завершаются явной ошибкой.

Pollinations может делать результаты доступными по публичным media URL — это указано рядом с полем подключения. Программа передаёт референсы inline только по запросу пользователя; отдельного публичного хостинга входных файлов она не создаёт. Документация сервиса: https://gen.pollinations.ai/docs .


Во время генерации медиа орб становится градиентным в цветах обводки, а по реальному тексту статуса раз в секунду проходит цветная волна. Системное отключение анимации учитывается. Журнал инструментов показывает использованный плагин, момент запуска от начала ответа и измеренную длительность. Запись раскрывается для времени начала/конца и результата; после завершения история сворачивается внутри итогового блока, без повторного списка изменённых файлов.


Кнопка сервиса рядом с плюсом открывает сохранённые подключения чата (Gemini, OpenAI, Claude, DeepSeek, OpenRouter). Для каждого сервиса сохраняется собственный зашифрованный ключ и модель; отсутствующий ключ добавляется в соответствующем разделе настроек. Переключение начинает новый чат для выбранного сервиса, сохраняя неотправленный текст, файлы и плагины. Генерационные ключи не меняются. Escape закрывает меню, а не открывает главное окно. Меню раскрывается от кнопки и сворачивается обратно; подсказки стали короткими, с общим glass/blur оформлением. Многострочный ввод сохраняет высоту и прокрутку при добавлении и удалении строк на пределе четырёх видимых строк.

## Live voice calls

An empty message with no files or referenced media offers **Start call**. The existing microphone still handles dictation. Live conversations use the active Gemini/OpenAI chat key and separate model/voice preferences in Settings → Live voice. The animated call panel includes a voice picker, Mute, End call, duration and available transcripts. Changing voice ends the current session; press Start call to reconnect. Calls also end on Escape, hidden/unloaded widget, or a connection change.

Audio streams directly to the chosen API and is never saved. Available transcripts stay in the current in-memory chat for continuing by text. Headphones are recommended because the native audio path does not provide acoustic echo cancellation. API model access, quotas and charges depend on your account. Calls can use the chat agent's browser/computer/file/plugin tools and the local widget dispatcher when Allow actions is enabled. Other chat providers show an explicit unsupported state.

Live voice now supports actual actions: ask it to open a website and read current information, use the desktop through the chat agent, control a compatible player, save local calendar tasks, start focus or show desktop status. Enable Allow actions in Settings → Live voice; optional document/media plugins use your existing selections and connections. Browser/app actions run directly by default; enable Ask before browser and app control to restore confirmations for chat and calls. Esc/Stop remains available. Give a player profile/URL for statistics; blocked or unavailable data must be reported honestly. Ukrainian, English and Auto are the only language choices; Auto is the default and replaces saved Russian preferences. See docs/widget-ipc.md for the shared dispatcher and PowerShell 7 named-pipe client.


Desktop control includes left/right/middle clicks and bounded physical key holds (letters, digits, F1-F12, navigation and Ctrl/Shift), with release on cancellation. Actual Dota 2 gameplay and real-time game performance are not verified.
