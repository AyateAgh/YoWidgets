# Official YoWidgets content

Generated by `node scripts/publish-catalog.mjs`. Packages contain only declarative widget/style JSON. Catalog hashes cover the exact ZIP bytes. Publish a new immutable package version when resources change. No API keys, settings or account data are used.
# Schema v1

Use `v1/catalog.json` as the production feed. `node scripts/publish-catalog.mjs` generates deterministic ZIPs containing style.json or widget.json. These small resources are consumed by the native renderer shipped in the app. New compatible styles need metadata and resources; new behavior needs an engine update.

Publish the feed and ZIPs together. Increment package versions when changing resources. Use a new feed directory for a breaking schema. `collectionName`, tags and permissions drive discovery. Do not advertise unsupported capabilities.

Local development: `node scripts/serve-catalog.mjs`, then launch with `--catalog-url http://127.0.0.1:8769/catalog.json --data-dir <isolated-directory>`. Development URLs are explicitly rewritten to loopback; production uses HTTPS.
