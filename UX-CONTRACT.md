# YoWidgets interaction contract

Locale: en-US, OS timezone. Source track names, notification bodies, user input and assistant responses retain their original language. Native WPF UI, not a browser application. Canonical owner is explicit for each recurring behavior.

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
|---|---|---|---|---|
| Form | Ui.Input, PasswordBox, MainWindow settings | This contract | ordinary / secret | native UI state inspection |
| Select/Listbox | Windows native context menu | DESIGN.md | widget S/M/L | keyboard and menu |
| Date | WidgetCards.Calendar | This contract | display only | month/day layout |
| Scrollbar | Controls.xaml + native ScrollViewer | DESIGN.md | vertical page / widget text | screenshots and keyboard |
| Toast | MainWindow.Status | This contract | info / error text | UI Automation live region |
| CRUD | WidgetManager, SettingsStore | cleanup-contract.md | enable / add / disable | tests + restart |

Enable/add immediately opens the widget and persists state. Disable closes only that widget. Disabling all also stops data activity and removes owned autostart. Snooze hides widgets and cancels data work; resume refreshes only enabled services. Closing management retains the tray; explicit Exit disposes the application. Full uninstall is enabled only in a validated installed copy; source workspace deletion is blocked.

Missing weather has no invented temperature. Failed refresh preserves previous values and reports error. Media actions use source capabilities and report rejection. Missing notifications consent/identity is visible; local hiding never clears Windows notification history. AI requires a selected service and an encrypted API key with manual send; native Gemini and OpenAI destinations are fixed and redirects are disabled. No endpoint field is required. Input and key text are never logged.

Async generations and cancellation prevent obsolete work applying after suspension. Settings write via a temporary file and keep a recovery copy. Bad JSON is preserved as .corrupt. Widgets are independent floating windows, with no Explorer parent. They are clamped to an attached work area; reset positions uses a centered grid. Duplicate instance IDs normalize to distinct IDs so cleanup cannot lose a window.

Keyboard: Tab/native controls, native context menus, arrow/Shift+arrow positioning, Escape opens management. File picker popup is intentionally OS-owned. No browser alert/confirm/prompt. The separate removal page describes exactly what the terminal delete button removes before execution. Common system parameter rollback is explicit and conflict-aware.

Native equivalents replace HTML/ARIA-only audit items: accessible WPF names, AutomationProperties.LiveSetting, native control focus and keyboard actions. Unsupported hardware/consent scenarios must be labelled unverified in docs/verification.md.

Media artwork order: valid current-track thumbnail → known website logo (or native application identity icon) → no artwork and no reserved square. Resolution is asynchronous, bounded, cancellable and guarded against stale track results. Unsupported browser websites are not guessed. Lyrics and expand controls have named vector icons; unavailable source capabilities remain disabled. Native drag preserves persisted physical coordinates; mixed-DPI and cross-monitor motion need separate physical testing.

Historical 0.4 (superseded by 0.5): MaterialPackage accepted only glass/live. Changing it applies to existing widget windows without restarting. Live native windows are non-activating tool windows, have no taskbar entries and own no system configuration. Snooze removes both native and WPF surfaces. Unsupported composition falls back to Glass. The live blur radius is system-owned; ineffective Glass-only sliders are omitted in Live mode.

Queue commands appear only when supported by the active music transport. Video sources and stopped/closed sessions retract them; paused music retains them. Source changes animate over 220 ms; reduced animation applies final state directly. Hidden/unsupported controls cannot be clicked or keyboard focused. Previous/next remain source-owned queue operations. Timestamp-based position is independent of metadata and artwork loading. A synthetic labelled SMTC fixture is available for transport validation without audio, credentials or an external music service.

0.5 pack contract: Widgets opens a two-pack library (Glass, Liquid Glass). Explore opens the selected pack; All packs returns to the library. Enable/disable/add operate on kind + Pack, never all instances of a kind across packs. Disable this pack closes only its enabled instances; Disable all remains the global shutdown action. Both packs can run together and retain their identity after save/restart and Snooze. Existing instances default to liquid and retain geometry/IDs. Material/tint/blur controls and the legacy global material state are removed; Appearance holds behavior and placement only. Pack definitions are a strict built-in allowlist. No downloaded code is loaded.

Every production desktop material uses current background pixels supplied by Windows, or a neutral transparent fallback when unavailable. It never paints a saved system wallpaper over live/animated content, including after composition/device policy changes. The old WallpaperProvider exists only in a historical diagnostic tool and is not compiled into YoWidgets. Style previews are explicitly authored, not claimed as live desktop snapshots. A native Composition Backdrop feeds an explicit GPU Gaussian effect (sigma 2/3 for Glass/Liquid; 4.5 during Liquid interaction). No unblurred duplicate is mixed over it. HostBackdrop is not used in the production renderer. Full Apple lensing, shape merging and pixel parity are not claimed.

BackgroundContrast owns one shared 2-second timer and at most one background job. It reads four RGB color values in each visible widget's transparent outside margins to estimate light/dark ink; it never captures or stores an image. The compositor backdrop itself remains unreadable. Hysteresis plus a 220 ms ink transition prevents flicker. Moving windows are not sampled synchronously in drag/render callbacks; obsolete readings are discarded after movement, Snooze, close or disposal. The timer stops with no widgets or in Snooze. This is a margin-based contrast estimate, not per-pixel Apple vibrancy.

0.5.1 lyrics contract: Lyrics only appears for confirmed available text on the current music source with the user's LRCLIB opt-in enabled. Missing/instrumental/video/error/loading states collapse the control entirely. Confirmed timed text follows the actual media clock, pausing and seeking with it. Plain text is available as explicitly untimed text. No transcript/audio capture or word-level timing is fabricated. Enable in Settings triggers the current track lookup immediately. Metadata/transport changes clear old text before awaiting a replacement; all result and failure commits check the current generation. Both widget packs use the same MusicView/LyricsView behavior. Desktop players do not require a browser but must publish a Windows media session; Shuffle/Repeat are not invented for sources which do not offer those commands.

0.5.2 bridge contract: an optional, separately installed Chrome/Edge extension reads only SoundCloud miniplayer metadata and queue controls. Fixed extension Origin, localhost-only WebSocket, bounded payloads, unique exact current-track/duration/playback-state routing and source acknowledgement are required. No local queue or optimistic mode mutation. No account credentials are imported from another project. Native SMTC remains the desktop-player path; unsupported native versions and arbitrary video subtitles are not claimed. Snooze/exit closes the listener. The manually installed browser entry is removed in the browser's Extensions page, separately from Windows uninstall. The diagnostic --inspect-widget-windows flag exposes existing widget windows in taskbar/accessibility inventory only during an explicit test launch; it adds no IPC command interface and is off in normal launches.

AssistantSettingsView is the canonical AI connection form; native ComboBox owns provider/model selection, PasswordBox owns secret entry, and inline feedback owns validation/check results. Save does not generate text. Check connection explicitly lists models at the selected fixed service and never saves a new secret automatically. Switching services requires a new key. Legacy model "Gemini" migrates to Gemini Flash Lite. Old endpoint values are retained only as inert compatibility data; they are never used as a credential destination.

AssistantView / AiService own one shared in-memory desktop conversation and draft, with explicit new-chat clearing. Full prior completed turns are sent within a bounded 64k-character/40-message request context. Incomplete/failed turns stay visible but do not enter later context. No transcript is written to disk. Changing connection clears the session to prevent sharing prior content with another account. Enter sends; Shift+Enter inserts a newline; IME composition cannot send. Stop/Escape cancels active work and preserves partial output; retry replaces the last attempt. Keys and prompt contents are never logged. HTTP/2 is preferred with platform fallback, chat generation and header waits have no application deadline; user cancellation and service/network errors end requests. No automatic billable retry is performed.

The microphone focuses the composer and invokes Windows voice typing; Windows owns microphone consent, language, recording UI and recognition. Dictation edits a draft only. Clipboard operations happen only on Copy actions, and failures remain visible. API/service failures appear inline with recovery. Assistant text cannot execute markup or code. Future desktop program/chat bridges remain outside the API widget and are not implied by a saved Gemini key.

## Compact assistant behavior (current; supersedes earlier size/dictation details)

AssistantLayout and WidgetWindow own anchored 72/160/540 DIP height states, with 260 ms motion and reduced-motion fallback. Native bounds checks must show zero composer-edge displacement for both upward and downward expansion. On drag the collapsed anchor is persisted. Collapse preserves chat; new chat clears conversation, draft and attachments. Session changes cancel pending file reads and transcription so stale content cannot return after reset or account changes.

AssistantProtocol has fixed native Gemini, OpenAI, Claude, DeepSeek and OpenRouter adapters. A generic API key cannot identify every service; provider/model selection stays in AssistantSettingsView, never in the widget header. OpenRouter accepts namespaced model IDs. Claude uses x-api-key/anthropic-version and native message events. DeepSeek uses its own origin and max_tokens. No user-entered URL or redirect receives credentials. Live validation of additional providers requires their own keys.

AssistantAttachment snapshots selected files in memory: at most 5 files, 8 MB each, 12 MB total; extracted text is bounded to 48k characters per document. UTF-8 text/code, Office text and bounded ZIP text extraction work across adapters. Gemini accepts supported PDF/image/audio/video inline inputs; OpenAI and Claude accept their native PDF/image parts. DeepSeek is text-only in this adapter; OpenRouter accepts text/images. Unsupported binary files or incompatible service/file combinations fail visibly. Office images are not extracted; ZIP binary entries are explicitly listed as names only. No file bytes leave the device before Send; retry reuses the same snapshot. Original files are never modified and no remote upload resources are created.

Voice input is explicit and never auto-sends a chat message. Gemini/OpenAI record mono PCM audio in memory via the default Windows input device, with a red/pulsing microphone indicator, click-to-stop, speech/silence detection and a 30-second cap. Recorded audio is sent to the selected service for transcription into the editable draft; user edits are preserved. Other providers use System.Speech only if a Windows recognition language is installed. Missing hardware/permissions/languages and API failures are visible. Escape, unload, Snooze, new chat and configuration changes stop capture and cancel transcription. No recording is written to disk. API usage follows the selected service plan. The previous Win+H shortcut implementation is removed.

The absence of an idle title is an explicit user design requirement. Better Design's generic missing-heading heuristic is inapplicable to this compact composer; the window/control retain accessible names. No title is added to satisfy that heuristic against the requested design.


## Voice and motion refinement (current)

AssistantView keeps the compact titleless glass composer. The chosen service's bundled SVG mark appears beside the input and moves into the response header when opened. AssistantSettingsView uses the shared dark native ComboBox template with SVG items, focus, keyboard navigation and scrolling; it never exposes a provider URL. PremiumIcon owns bundled vector glyphs throughout navigation, management, catalog previews and widget controls. Lucide outlines and Iconimate's gear replace Unicode icon glyphs. HoverMotion runs one 650 ms gesture on hover and repeats every 5 seconds only while hovered; cooldown survives re-entry/content replacement, and leave/unload/hidden/reduced-motion stop it. Idle icons have no timers. VoiceGlow and ThinkingOrb render at up to 30 fps only while active and visible, with static reduced-motion fallback. Audio levels come from the recording device (System.Speech AudioLevelUpdated on its local path), never random animation values in production.

Gemini dictation uses the dedicated gemini-3.5-transcribe model through the fixed Google Interactions endpoint with inline WAV and store:false, independently of the chat model. Response status must be completed; only model_output text is accepted. No remote file resources are created. OpenAI keeps its dedicated transcription endpoint. The recorder stops after 800 ms of detected silence instead of 2.5 seconds and retains its 30-second cap. Transcription has no application deadline and can be cancelled with the microphone button or Escape; cancellation/session guards prevent stale draft updates. No automatic billable retries are made. The 3–5-second goal is a latency target, not a guarantee against provider/network delays.

Expanded conversations animate the compositor's live backdrop blur to 8 px over 260 ms, returning to the pack's 2/3 px base when collapsed. Text is never blurred. Readability state survives material recreation and combines with drag/resize blur. No screenshot or wallpaper image is used as a glass background.

## Optional file-agent access

Selecting or changing a folder starts a new chat; the folder chip can disable access. Provider changes and process restart clear file access. The API key remains DPAPI-protected and fixed service endpoints remain authoritative.

Native tool adapters exist for Gemini, OpenAI, Claude, DeepSeek and OpenRouter; the selected model must support function/tool calling. Only Gemini has been exercised with a real account key. Tools list/search/read files, create folders/files, edit text and delete individual files inside the chosen folder. Existing-file mutation requires the latest read hash. UTF-8 editing preserves unrelated text and BOM; binary creation uses base64. Image reading supports PNG/JPEG/WebP for vision-enabled adapters. Other binary reads and unsupported vision adapters fail explicitly. No terminal, program control, package installation or full-disk access is supplied.

Activity rows show executed tool names, paths, completion/errors and real line counts. The change card appears even for partial runs; a 500 ms hover previews the before/after diff or raster image, and clicking opens a larger review. The preview remains while hovered and fades after leaving both row and menu. Undo is unavailable while generating and checks every current file before restoring originals. Newer manual changes are preserved. Undo backups and chat history are in memory only, lost on new chat, folder change or app exit. Workspace confinement and reparse/hard-link checks are application safeguards, not a hostile-local-process security boundary. Limits and truncated previews are visible rather than silently dropping operations.

Current presentation: a file-agent turn has one combined action/orb status. Live actions can expand inline to inspect the current cumulative diff; hovering an action filename shows its full absolute disk path after 500 ms. Completed action elements remain stable while later operations arrive. The final change card appears once generation stops; the earlier journal is collapsed inside it, including after cancellation or failure. Stopping never rolls back already completed file work. User/assistant copy and retry actions stay clickable while crossing their spacing, during a 260 ms leave bridge and throughout the subsequent fade, and remain visible with keyboard focus.
